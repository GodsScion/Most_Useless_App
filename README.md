Well, I don't know why anyone would even take a look at this 😑. But, if you're curious 🫣 https://godsscion.github.io/Most_Useless_App/

# What's inside
- **Change Text Cases** 🔠: fix Caps Lock accidents.
- **Toss a Coin** 🪙: for decisions you refuse to own.
- **Balance Work & Life** 🕰️: when can I leave?
- **Name Your Startup** 🦄: all the good names are taken, so roll the dice. Get names built from syllables, total chaos, or spins on a word you like, never the same one twice. Then see which of `name.com`, `heyname.com` and `meetname.com` nobody has grabbed yet (it asks the public registry, no login needed).
